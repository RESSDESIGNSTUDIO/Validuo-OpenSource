# `.ai/specs/` — specyfikacje (Spec-Driven Development)

Specyfikacje opisujące planowaną pracę (nowe funkcje, refaktory, zmiany architektury), zanim powstanie kod.

- Format nazwy pliku: `YYYY-MM-DD-slug.md` (np. `2026-10-21-user-auth-refresh.md`).
- Aktywne, jeszcze niezrealizowane specyfikacje trzymaj bezpośrednio w `.ai/specs/`.
- Po wdrożeniu — przenieś plik do `.ai/specs/implemented/`.
- Specyfikacje porzucone, zastąpione lub nieaktualne — przenieś do `.ai/specs/archive/` (nie usuwaj).

Pełne zasady korzystania z tego katalogu patrz `AGENTS.md`.
