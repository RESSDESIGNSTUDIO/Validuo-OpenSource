# `.ai/runs/` — logi autonomicznych przebiegów AI

Log każdego autonomicznego przebiegu agenta AI (np. praca w tle, pętle `/loop`, dłuższe sesje bez bieżącego nadzoru człowieka).

- Format nazwy pliku: `YYYY-MM-DD-slug.md` (np. `2026-10-21-migrate-db-schema.md`).
- Log powinien zawierać: cel przebiegu, podjęte kroki/decyzje, napotkane problemy, wynik końcowy i ewentualne kolejne kroki.

Pełne zasady patrz `AGENTS.md`.
